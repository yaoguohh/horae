Horae 弹窗设计

选定的是表格这一版。下面是它在各个状态下的样子，以及点底部按钮进去的三个页面。每个弹窗都可以点：导航、展开和菜单是真的，“更新”“暂停”只做展示。

主弹窗

头部一句话说现在怎样；中间是来源表；底部左边暂停或恢复自动更新，右边两个图标是日志和设置。

点进去的页面

日志从底部的日志图标进；设置从齿轮进；管理来源在设置里。

这一版的要点

  • 整体是灰白的。彩色只有三处：来源的品牌小图标、进行中的蓝、未成功的一个小红点和暗红色的字。
  • 标志是淡蓝底上的蓝色 H，任何状态下都不变。按钮都是灰色的，没有实心蓝按钮。
  • 每行四样：品牌小图标、名称、上次、下次最早。进行中和未成功的行多一行说明。
  • 单个来源的“更新”和“更多”平时不显示，鼠标移到那一行时出现在时间列的位置。
  • 底部只有三样：暂停或恢复自动更新、日志、设置。管理来源、通知、登录时打开、软件更新、退出都在设置里。
  • 暂停时，底部左边变成“恢复自动更新”并写明暂停到何时；头部空着时也会说一遍。
  • 未成功的来源写明自动重试的最早时刻：失败按周期退避，周更的来源失败后要一周才自动重试。
  • 浅色和深色都有，跟随系统。
